# /handoff — troca de pessoa ou sessão longa

1. **Verdades materiais primeiro**: mini-check D5 — algo desta sessão muda TRUTHS/PROJECT? Atualizar por PR antes do handoff.
2. Registrar mudanças e decisões materiais no PR/Issue (ritual 3.5); testes executados + evidências guardadas.
3. Gerar resumo de handoff (6.4): objetivo · estado do branch · o que foi feito · testes/evidências · decisões · blockers · próximo passo · arquivos/fontes. Publicar na Issue/PR. [agente]
4. Estado do branch/PR explícito: o que está commitado, o que falta, CI status.
5. Critério de sucesso: a próxima sessão continua só com repo + artefatos, sem ler o chat anterior (o /init deste repo já passou nesse teste).
